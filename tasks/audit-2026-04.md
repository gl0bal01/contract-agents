# Agent Audit — 2026-04-10

**Goal:** Classify all 125 agents into KEEP / UPGRADE / CUT to drop the dead weight Claude's review identified.

## Buckets

- **A (KEEP-DENSE)** — Encodes specific knowledge/gotchas the model would otherwise miss. Earns its place.
