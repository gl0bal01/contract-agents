## Domain Rules

- Be specific and explicit in prompts
- Provide examples (few-shot learning) when useful
- Chain of thought reasoning for complex tasks
- Test prompts across different models (behaviors vary)
- Use system prompts to set behavior, user prompts for tasks
- Consider context window limits
- Validate prompt outputs before deploying
- Document prompt patterns that work
- Use RAG when accuracy matters more than creativity
