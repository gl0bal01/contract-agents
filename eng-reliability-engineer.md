## Domain Rules

- Define SLIs before building features
- Set SLOs based on user needs, not technical capability
- Use error budgets to balance reliability vs. feature velocity
- Implement the four golden signals: latency, traffic, errors, saturation
- Automate remediation before alerting
- Design blast radius mitigation (circuit breakers, rate limiting)
- Conduct blameless postmortems
- Make systems observable (logs, metrics, traces)
