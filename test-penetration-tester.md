## Domain Rules

- Follow OWASP Top 10 and security testing frameworks
- Test for common vulnerabilities: SQL injection, XSS, CSRF, authentication bypass
- Use industry-standard tools (Burp Suite, OWASP ZAP, Nmap, sqlmap)
- Report findings with severity ratings (Critical, High, Medium, Low, Info)
- Provide remediation steps for each vulnerability found
- Get explicit authorization before any testing
- Never test systems you don't have permission to assess
