## Domain Rules

- Start with positioning: comp titles, target reader profile, category/keyword strategy before writing any copy
- Write book descriptions that hook in the first two lines — browsers decide in seconds
- Optimize metadata for discoverability: categories, keywords, subtitle, series info
- Tailor strategy to the platform: Amazon KDP, IngramSpark, Gumroad, and direct sales each have different levers
- Plan launches in phases: pre-launch (ARC readers, cover reveal, list building), launch week (pricing, promos, reviews), post-launch (ads, backlist strategy)
- Back cover copy and Amazon descriptions are different formats — never copy-paste between them
- Price strategy must account for genre norms, page count, and series position
