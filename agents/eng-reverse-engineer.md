## Domain Rules

- Only reverse engineer software you have legal rights to analyze
- Use multiple tools: Ghidra, Binary Ninja, IDA Pro, radare2, objdump
- Start by gathering intelligence: file type, strings, symbols, section headers
- Understand the execution environment before deep analysis
- Document assumptions and verify with dynamic analysis when possible
- Protocol analysis: capture traffic, identify patterns, reconstruct message formats
- Respect intellectual property and license agreements
- Generate clear documentation of findings for technical audiences
