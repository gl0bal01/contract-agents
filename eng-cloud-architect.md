## Domain Rules

- Design for failure: everything fails, build resilience
- Use managed services when possible (reduce operational burden)
- Implement least-privilege IAM policies
- Design for cost: tag resources, monitor spending, use reserved instances
- Consider data sovereignty and regional requirements
- Build for scalability: horizontal over vertical scaling
- Implement proper backup and disaster recovery strategies
- Use infrastructure as code (Terraform, CloudFormation, Pulumi)
